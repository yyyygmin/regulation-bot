# 규정봇

신입사원이 휴가·경비 규정을 문장으로 물으면, 샘플 규정 문서 2종에서 찾아 근거와 함께 답하는 실습용 채팅 서비스입니다.

**지금은 실제 AI를 연결하지 않은 상태입니다.** 답변은 질문의 단어를 규정 문서와 비교해 만든 테스트용 가짜 답변이며, 비용이 나가지 않고 질문도 외부로 나가지 않습니다. 샘플 규정도 실습을 위해 지어낸 내용입니다.

## 할 수 있는 것

- 질문을 입력하거나 첫 화면의 질문 버튼 5개를 눌러 답변과 근거(문서 이름과 조항 번호)를 봅니다.
- 답변이 5문장을 넘으면 앞의 5문장만 보이고, "더보기"를 누르면 조항 원문이 열립니다.
- 문서에 없는 내용은 "찾지 못했습니다"라고 답하고, 모호한 질문은 한 번 되묻습니다.
- 같은 화면 안에서 이어서 물을 수 있고, 새로고침하면 처음부터 시작합니다. 대화는 어디에도 저장하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. API 키가 없어도 실행됩니다.

## 확인

```bash
npm run lint
npm run build
```

시험용 환경 변수 `MOCK_AI_SCENARIO`에 아래 값을 넣고 서버를 시작하면 특정 상황을 일부러 만들 수 있습니다. 배포 환경에는 등록하지 않습니다.

`error`, `timeout`, `bad-format`, `fake-citation`, `no-citation`, `too-many-citations`, `clarify`

## 보호 장치

- **보안 헤더:** 모든 응답에 붙습니다. 외부 스크립트 실행과 다른 사이트의 화면 삽입을 막고, `x-powered-by`는 보내지 않습니다. (`next.config.ts`)
- **요청 본문 상한:** 질문과 이전 대화를 합쳐 한글 1,000자(3,000바이트)까지만 받습니다. 넘으면 413으로 거절하고, 화면은 오래된 대화부터 빼서 보냅니다.
- **호출 횟수 제한:** 같은 접속 주소에서 분당 20회, 시간당 150회까지 받습니다. 넘으면 429와 안내 문구를 보여줍니다. 값은 `lib/constants.ts`에서 바꿉니다. 횟수는 서버 메모리에 두어 서버가 여러 개면 각각 셉니다.
- **입력 검사:** 질문은 500자까지, 전화번호·주민등록번호 형식은 전송 전에 막습니다.

## 배포 전에

- 이대로 배포하면 공개 화면에도 테스트용 가짜 답변이 나옵니다. 답변마다 "테스트용 가짜 답변입니다." 표시가 붙습니다.
- 공개 전에 남은 보완 항목은 [CHECK.md](CHECK.md)에 우선순위 순으로 있습니다.
- 화면 색상은 캠코 CI 색상을 기준으로 했고 로고와 기관 이름은 쓰지 않았습니다. 외부에 공개하기 전에는 CI 사용 규정을 확인하세요.
